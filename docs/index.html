Sigil index

A public, git-backed index of signed trust badges for MCP servers. Every badge is cryptographically verified by CI before it lands here. A badge attests to the exact version scanned, nothing more.

Index repo Sigil

Publish a badge

sigil scan ./my-server --sign --badge-out my-server.trust.json
sigil publish --badge my-server.trust.json
# or one step:
sigil scan ./my-server --sign --publish

Publishing opens a pull request against this index. CI verifies the badge's Ed25519 signature and schema before a maintainer merges it.

Honest limitations: a badge attests to the exact version scanned at a point in time; a new release needs a new scan. Static checks are heuristics with false positives. Trust in the signer (the key id) is out of band, like a PGP key id: the index proves a badge is intact and well-formed, not that its signer is honest. Verify any badge yourself with sigil verify badge.json.
